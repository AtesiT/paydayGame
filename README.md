# 🌴 NEON VAULT '84 — paydayGame 🎭

Кооперативный **heist-шутер с 3D-видом сверху** (Three.js/WebGL: перспективная камера,
зеркальный мраморный пол, bloom-неон) в духе Payday 2 и в эстетике неонового Майами 80-х:
светящиеся маски зверей, розово-циановый неон, синтвейв.

Все модели процедурно строятся в коде с PBR-материалами (нормальные карты ткани/кожи/металла):
персонажи с суставными конечностями и 3D-масками-оболочками, дверь хранилища со штурвалом,
мониторы терминалов, слот-машины, пальмы с альфа-листвой, фургон с бортовой графикой.

Маски — цельные головы животных (тигр/волк/панда/акула) с ушами, мордами и светящимися глазами;
у персонажей полноценные причёски. Анимации: отдача, перезарядка, работа руками, дыхание,
паника гражданских, бегущие огни автоматов, качающиеся пальмы. В лобби и в игре — кнопка
**«⚙️ Настройки графики»**: пресеты Авто/Низкое/Среднее/Высокое/Ультра, масштаб разрешения,
тени, отражения, bloom, атмосфера и счётчик FPS — для слабых и мощных ПК.

Визуальный стиль выдержан по концепт-арту: тёмный кинематографичный грейд с виньеткой,
каменные стеновые панели с фаской, плинтусы и пилястры, окна с рамами и закатом,
полосатый свет жалюзи на мраморе, запечённые тени у стен, улица с машинами и фонарями.

**До 4 игроков по локальной сети**, пустые слоты занимают **боты-напарники**.
Стелс и loud, дрели с заклиниванием, заложники, пейджеры охранников, камеры,
сумки с лутом, волны полиции → SWAT → FBI → щиты → **НЕОНОВЫЙ БЫК**.

## 🚀 Быстрый старт

```bash
npm install
npm start
```

Сервер напечатает адреса. Хост играет на `http://localhost:3000`, друзья в той же
Wi-Fi/LAN сети открывают `http://<IP-хоста>:3000`. Подключаться можно даже посреди
ограбления — займёте место бота. Один игрок = команда из вас и 3 ботов.

## 🎮 Управление

| Клавиша | Действие |
|---|---|
| `WASD` / стрелки | движение, мышь — прицел, `ЛКМ` — огонь |
| `E` (держать) | дрель, паковать лут, поднять своего, ответить на пейджер, связать, отключить камеры |
| `G` | надеть маску / бросить сумку |
| `F` | крикнуть «ВСЕМ ЛЕЖАТЬ!» |
| `V` | удар прикладом (тихий) |
| `R` | перезарядка |
| `Shift` / `C` | спринт (шумно) / красться (тихо) |
| `Q` | приказ ботам: таскать сумки ↔ авто |
| колесо мыши | зум камеры |

🤫 **Стелс:** вы начинаете в штатском (фаза разведки). Конусы зрения охраны и камер,
пейджеры убитых охранников (успеть ответить за 12 с, максимум 4), гражданские бегут
звонить в 911 — укладывайте криком и связывайте. Камеры отключаются на панели в
комнате охраны. Без тревоги — бонус «Призрак» +25% к выплате.

🚨 **Loud:** волны штурма с передышками, заложники замедляют полицию, стойки и столы —
укрытия от пуль. Раненый грабитель ждёт помощи 25 с, потом — под стражу.

🎭 **Маски с бонусами:** Тигр (+урон), Волк (+скорость), Панда (+HP/броня),
Акула (стелс и быстрые действия). Оружие: винтовка, ПП, дробовик.

## 🏗️ Архитектура

- `server.js` — авторитарный игровой сервер (Node.js + `ws`): симуляция 30 Гц,
  A*-патфайндинг, ИИ ботов-напарников, охраны, гражданских и полиции, стелс-детект
  (конусы зрения + LOS), директор волн штурма, дрели/лут/заложники.
- `public/index.html` — 3D-клиент на Three.js: перспективная «dollhouse»-камера,
  зеркальный мраморный пол (Reflector), объёмные персонажи с неоновыми масками,
  окна с закатом и пальмами, круглая дверь хранилища, bloom, HUD по углам экрана
  как на концепт-арте, мини-карта, синтезаторные звуки и синтвейв-музыка (WebAudio).
  Все текстуры и модели генерируются кодом. Колесо мыши — зум камеры.
- `public/classic.html` — запасная 2D-версия клиента (если WebGL недоступен).
- Three.js раздаётся сервером локально (`/vendor/...` из `node_modules`) — для LAN
  интернет не нужен.
- `scripts/` — автотесты (см. ниже).
- `concepts/` — этап концепт-арта: 9 визуальных стилей, из которых был выбран №3.

## 🧪 Тесты

```bash
npm start                       # в отдельном терминале
node scripts/test-client.js     # WS-протокол, боты, стрельба, тревога, волны
node scripts/test-heist.js      # полный цикл: дрель, сумки, фургон, финал
node scripts/test-client-ui.js  # настоящий Chromium (WebGL): лобби, старт, маска, стрельба, HUD
node scripts/screenshot.js bank # скриншоты 3D-клиента в screenshots/ (нужен Chromium)
node scripts/render-shot.js after # PNG-скриншоты мира (нужен npm i --no-save @napi-rs/canvas)
```
